분석하다 막히는 지점은 늘 같습니다. 무엇을 돌릴지, 나온 숫자가 좋은 건지, 이 결론을 말해도 되는지. 그 세 가지를 네 장에 담았습니다. 인쇄해서 모니터 옆에 두고, 분석할 때마다 훑어보세요.

어떤 분석을 돌릴까

순서 — 이 흐름을 벗어나면 대부분 헛수고가 됩니다

STEP 1질문 정하기 “매출을 올리고 싶다”는 질문이 아닙니다. 무엇을·얼마나·언제까지가 들어가야 분석할 수 있습니다.
STEP 2데이터 믿을 수 있나 합치고(🧬) · 정의 맞추고(🔍) · 품질 보고(🧹). 여기를 건너뛰면 뒤가 전부 틀립니다.
STEP 3일단 살펴보기 요약(📋)과 상관관계(🔗)로 지형을 봅니다. 가설은 여기서 나옵니다.
STEP 4질문에 답하기 비교 · 예측 · 이상탐지 · 분류. 아래 표에서 고르세요.
STEP 5의심하기 다른 이유는 없나(🔀). 이 단계를 하는 사람이 전문가입니다.

p값
우연일 확률		 p < 0.01매우 뚜렷 우연으로 이만한 차이가 날 확률이 1% 미만입니다
0.01 ≤ p < 0.05유의 통상적 기준(5%)은 넘었습니다. 재현되는지 한 번 더 확인하세요

차이의 크기		 |d| < 0.2무시 가능 p값이 “있냐 없냐”라면 d는 “얼마나 크냐”입니다.
데이터가 많으면 아주 작은 차이도 p<0.05가 되므로 반드시 함께 보세요.

퍼짐과 불확실성

이름수식한 줄 뜻
표준편차s = √( Σ(xᵢ − x̄)² / (n − 1) ) 평균에서 평균적으로 얼마나 떨어져 있나. n−1인 이유는 평균을 이미 써버려 자유도가 하나 줄었기 때문
z점수z = (x − μ) / σ “평균에서 표준편차 몇 개만큼 떨어졌나”. 단위가 다른 값을 비교할 때 씁니다
정규분포 눈금μ±1σ ≈ 68% · μ±2σ ≈ 95% · μ±3σ ≈ 99.7% 관리도의 3σ 선이 여기서 나옵니다 (밖으로 나갈 확률 0.3%)
표준오차SE = σ / √n 평균값이 흔들리는 폭. 정밀도를 2배로 하려면 데이터가 4배 필요합니다
신뢰구간x̄ ± tα/2, n−1 · s/√n “참값이 이 범위 안에 있을 것”. 구간이 0을 걸치면 차이가 있다고 못 합니다
필요 표본 수n ≈ 2(zα/2 + zβ)² σ² / δ² δ(찾고 싶은 차이)가 절반이 되면 필요한 표본은 4배가 됩니다

이름수식한 줄 뜻
공분산cov = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1) 같이 커지면 +, 반대면 −. 단위에 휘둘려 크기 비교는 못 합니다
상관계수r = cov(x,y) / (sx sy) = cos θ 공분산을 단위에서 해방시킨 값. 두 데이터 벡터가 이루는 각도의 코사인입니다
최소제곱 회귀β̂ = (XᵀX)⁻¹ Xᵀy 오차 제곱합을 최소로 만드는 계수. y를 X가 만드는 평면에 수직으로 투영한 것
결정계수R² = 1 − SSres / SStot “평균으로 찍는 것보다 얼마나 나아졌나”. 0이면 평균과 같고 1이면 완벽
로지스틱 회귀p = 1 / (1 + e−(β₀+β₁x)) 확률을 0~1 안에 가두는 S자 곡선. 계수는 로그 오즈의 변화량
교차엔트로피L = −Σ [ y log p̂ + (1−y) log(1−p̂) ] 확신에 차서 틀리면 벌점이 급격히 커집니다 (log 0 → ∞)
지니 불순도G = 1 − Σ pᵢ² 한 가지로만 모이면 0. 트리는 이 값이 가장 많이 줄어드는 질문을 고릅니다
정보이득IG = H(부모) − Σ (nᵢ/n) H(자식) 질문 하나로 줄어든 혼잡도. 트리의 분기 기준
K-means 목적min Σk Σx∈Ck ‖x − μk‖² 각 점에서 자기 중심까지 거리 제곱의 합을 최소화. 거리 기반이라 표준화 필수
실루엣s = (b − a) / max(a, b) a=내 그룹과의 거리, b=가장 가까운 남의 그룹과의 거리. 1에 가까울수록 잘 나뉜 것
편향–분산오차 = 편향² + 분산 + 잡음 모델을 단순하게 하면 편향↑, 복잡하게 하면 분산↑. 과적합의 정체가 이 분산입니다

SHEET 4

말하기 전에 확인할 것

잘못된 분석보다 잘못된 문장이 더 큰 사고를 냅니다

분석 시작 전 체크리스트

  • 첫 줄이 컬럼 이름인가 — 제목 줄·병합 셀이 위에 있으면 안 됩니다
  • 행 하나가 무엇인가 말할 수 있나 — “설비 1대의 하루”처럼
  • 숫자 컬럼에 글자가 섞이지 않았나 — “측정불가”, “-”는 빈칸으로
  • 날짜 형식이 하나로 통일됐나 — 2026-01-05 / 26.1.5 혼용 금지
  • 같은 뜻의 값이 다르게 적히지 않았나 — A라인 / a라인 / A_line
  • 단위가 도중에 바뀌지 않았나 — g ↔ kg, 초 ↔ 분
  • 기간이 충분한가 — 시계열은 최소 2주기 이상
  • 그룹별 개수가 너무 적진 않나 — 한 그룹 30개 미만이면 조심
  • 중복 행이 없나 — 파일을 합쳤다면 특히
  • 결과에 답이 미리 들어있진 않나 — 불량 예측에 “불량사유” 컬럼 넣기

결론 내리기 전 7가지 함정

1. 상관 ≠ 인과

아이스크림 판매와 익사 사고는 같이 늡니다. 원인은 여름입니다.

→ 🔀 교란변수 점검으로 제3의 변수를 확인하세요
2. 심슨의 역설

전체로 보면 신형이 나쁜데, 온도대별로 나눠 보면 모든 구간에서 신형이 좋을 수 있습니다.

→ 나누어 봤을 때도 같은 결론인지 반드시 확인
3. p값의 오해

p=0.03은 “가설이 맞을 확률 97%”가 아닙니다. 차이가 없다고 가정했을 때 이런 결과가 나올 확률입니다.

→ 효과 크기와 신뢰구간을 함께 말하세요
4. 많이 비교하면 뭐든 나온다

20개를 비교하면 아무 관계가 없어도 하나쯤은 p<0.05가 나옵니다.

→ 보정(Bonferroni)을 쓰거나, 가설을 먼저 정하고 보세요
5. 남은 것만 보고 있다

“퇴사자 설문”으로 만족도를 재면 이미 떠난 사람이 빠져 있습니다.

→ 이 데이터에 누가 빠져 있는지 먼저 물으세요
6. 범위 밖 예측(외삽)

온도 20~30℃ 데이터로 만든 모델에 50℃를 넣으면 숫자는 나오지만 근거가 없습니다.

→ 학습 데이터의 범위를 벗어나면 예측하지 마세요
7. 중요도 = 원인이 아님

모델이 “가장 많이 쓴 컬럼”일 뿐입니다. 결과와 함께 움직이는 결과 쪽 변수일 수도 있습니다.

→ 시간 순서를 확인하세요. 원인은 결과보다 먼저 옵니다

보고할 때의 문장

같은 결과라도 어떻게 말하느냐에 따라 신뢰도가 갈립니다. 오른쪽처럼 쓰세요.

✕ 이렇게 말하면 위험합니다✓ 이렇게 말하세요
“온도가 불량의 원인입니다” “온도와 불량률이 함께 움직입니다(r=0.62). 인과 확인에는 온도만 바꾼 실험이 필요합니다”
“A라인이 B라인보다 좋습니다” “A라인이 평균 2.3 높습니다(95% 신뢰구간 0.8~3.8, p=0.004). 실무적으로 의미 있는 크기입니다”
“차이가 없었습니다” “차이가 있다고 볼 근거는 부족했습니다(p=0.21). 현재 표본으로는 3 이하의 차이는 잡아내기 어렵습니다”
“다음 달 매출은 1억 2천입니다” “1억 1천~1억 3천으로 예상됩니다(과거 검증 오차 8%). 프로모션 같은 신규 요인은 반영돼 있지 않습니다”
“정확도 95%짜리 모델입니다” “실제 불량 100건 중 87건을 잡아내고 13건을 놓칩니다. 정상을 불량이라 하는 헛걸음은 100건당 4건입니다”
“이상치 47건을 찾았습니다” “평소와 다른 패턴 47건을 표시했습니다. 불량 여부는 현장 확인이 필요하며, 상위 10건부터 보시길 권합니다”
마지막 점검 한 문장. “이 결론이 틀렸다면, 가장 그럴듯한 이유는 무엇일까?” — 여기에 답할 수 있으면 보고해도 좋습니다. 답이 떠오르지 않는다면 아직 데이터를 충분히 보지 않은 것입니다.
