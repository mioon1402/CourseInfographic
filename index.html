무엇을 분석할 수 있나요

데이터를 합치고 점검하는 것부터, 예측하고 원인을 따지는 것까지 15가지입니다.

🧬 데이터 준비

  • 여러 파일 합치기 — 흩어진 표를 하나로
  • 품질 진단·자동 정제 — 빈칸·중복·오타
  • 정의·단위 점검 — 숫자의 뜻이 맞는지

🔍 전체 파악

  • 자동 요약 리포트 — 데이터 첫인상
  • 상관관계 히트맵 — 무엇이 함께 움직이나

⚖️ 비교·검정

  • 그룹 간 차이 비교 — 차이가 진짜인가
  • 교란변수·층화 비교 — 정말 그 탓인가

📈 시간 흐름

  • 미래 예측 (Prophet) — 앞으로의 값
  • 평활화·트렌드 추출 — 진짜 흐름

🏭 감시·품질

  • 이상치 감지 — 평소와 다른 신호
  • 공정 관리도 (SPC) — 안정적인가
  • 파레토 분석 — 무엇부터 고칠까

🤖 예측 모델

  • 수치 예측 — 결과 값 맞히기
  • 상태 분류 — 정상/불량 판정
  • 군집화 — 유형별로 묶기

이런 점이 다릅니다

🧭 결과를 읽어 드립니다

숫자만 던지지 않습니다. “실제 불량 100건 중 87건을 잡아내고 13건을 놓칩니다” 처럼 현업 언어로 풀어서 설명합니다.

⚠️ 잘못된 사용을 말립니다

계속 늘어나는 값에 관리도를 쓰면 왜 맞지 않는지 먼저 알려 드립니다. 결과를 그대로 내놓지 않습니다.

🔒 데이터는 내 손을 떠나지 않습니다

이 사이트는 컬럼 이름만 브라우저 안에서 읽습니다. 실제 데이터는 본인의 구글 Colab 에만 올라가고 세션이 끝나면 사라집니다.

📦 리포트를 그대로 공유

결과는 인터넷 없이도 열리는 HTML 파일로 저장됩니다. 동료에게 그냥 보내면 그래프까지 그대로 보입니다.

자주 묻는 질문

프로그램을 설치해야 하나요?

아니요. 브라우저만 있으면 됩니다. 분석은 구글 Colab(무료)에서 실행되므로 구글 계정만 필요합니다.

파이썬을 몰라도 되나요?

네. 코드를 읽거나 쓸 일이 없습니다. 버튼과 드롭다운만 쓰시면 되고, 타이핑할 것도 없습니다.

제 데이터가 외부로 나가나요?

이 사이트에 올린 파일은 전송되지 않습니다. 컬럼 이름을 알아내려고 브라우저 안에서 앞부분만 읽습니다. 실제 분석 데이터는 본인 구글 계정의 Colab에만 올라가며, 세션이 끝나면 함께 사라집니다.

분석할 파일이 없는데 구경만 해볼 수 있나요?

가능합니다. 분석하기 화면에서 [🧪 예제 데이터로 연습] 을 누르면 공장 설비 기록 예제로 모든 기능을 체험할 수 있습니다. 파일을 올릴 필요도 없습니다.

결과가 이상하게 나옵니다.

대부분 데이터 자체의 문제입니다. 데이터 품질 진단을 먼저 돌려 보시고, 여러 라인·기간을 섞어 비교하신다면 정의·단위 일관성 점검도 함께 확인해 보세요.

연습할 데이터가 없습니다.

분야별 연습용 데이터셋 4종(제조·유통·고객·병원)을 준비해 두었습니다. 배우기 → 9장 에서 내려받으세요. 각 데이터에는 심슨의 역설·불균형 데이터 같은 학습 포인트가 일부러 심어져 있습니다.

수학적으로 검증하고 싶습니다.

배우기 → 6장 에 실제 수식이 정리되어 있습니다. 표준오차 σ/√n 부터 최소제곱 정규방정식, 로그오즈, 지니 불순도, Cpk 유도, 편향-분산 분해까지 기호를 하나씩 풀어서 설명합니다.

어떤 분석을 골라야 할지 모르겠습니다.

두 가지 방법이 있습니다. 질문 만들기 로 세 번 클릭해 추천을 받거나, CSV를 올리면 데이터 구성을 보고 어울리는 분석을 자동으로 추천해 드립니다.
