STEP 1

무엇을 알고 싶으신가요?

목적에 가장 가까운 카드를 하나 고르세요. 용어를 몰라도 괜찮습니다 — 카드에 적힌 질문 문장으로 고르시면 됩니다.

STEP 2

데이터 연결하기 (선택이지만 강력 추천)

CSV를 올리면 컬럼을 목록에서 골라 쓸 수 있어 오타 걱정이 사라지고, 어울리는 분석도 추천해 드립니다.

📄
CSV 파일을 끌어다 놓거나 클릭해서 선택
엑셀에서 저장한 한글 CSV(cp949/euc-kr)도 자동 인식합니다
🧪 파일 없이 연습하기
공장 설비 기록 예제로 모든 분석을 바로 시험해 볼 수 있습니다. Colab에서 파일을 올릴 필요가 없습니다.
🧪 예제 데이터로 실행합니다. Colab이 예제를 직접 만들어 내므로 파일을 올리실 필요가 없습니다.
🔒 올리신 파일은 어디에도 전송되지 않습니다. 컬럼 이름을 알아내려고 브라우저 안에서 앞부분만 읽을 뿐입니다.
그래서 Colab에서 같은 파일을 한 번 더 선택해 주셔야 합니다. 포털(내 컴퓨터)과 Colab(구글 서버)은 서로 다른 곳이라, 데이터를 자동으로 넘기려면 파일을 외부 서버에 올려야 하기 때문입니다.

🧭 실행 요약
먼저 STEP 1에서 분석을 선택해 주세요.
분석을 선택하면 실행 링크가 여기에 표시됩니다.
💡 Colab에서는 이렇게
1. 새 탭이 열리면 상단 메뉴 [런타임] → [모두 실행] 을 누르세요. (단축키 Ctrl+F9)
2. 파일 선택 버튼이 뜨면 CSV를 올리세요. (없으면 취소 → 예제 데이터로 진행)
3. 컬럼은 드롭다운으로 고르면 됩니다. 타이핑할 것은 없습니다.
4. 그래프와 한국어 해석 리포트가 자동으로 만들어지고 ZIP으로 저장됩니다.
💡 결과를 보고 컬럼을 바꾸고 싶으면 노트북 2단계 드롭다운만 바꾸고 3단계 셀만 다시 실행하세요. 파일을 다시 올릴 필요 없습니다.
